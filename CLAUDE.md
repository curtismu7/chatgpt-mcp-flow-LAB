# chatgpt-mcp-flow-LAB

Tier **Demo**. A neutral teaching app: how a remote MCP server behind an enterprise front door is authorized when a public AI assistant calls it for a signed-in user (PKCE, RFC 9728/8414/8707/9207, PingFederate + enterprise IdP, RFC 8693 on-behalf-of). Mock only; no real product is contacted. Repo `https://github.com/ping-sandbox/chatgpt-mcp-flow-LAB`. Catalog id D25 is a PLACEHOLDER carried over from the old repo ("to confirm"); do not present it as assigned. Node 26 only, Docker/OrbStack only (never Docker Desktop), no SE k8s build (deferred by the owner, 2026-10-31).

## Run and test
- `npm ci`, `npm run build`, `npm start` (server 6650, mock actors 6651-6655), `npm test` (server `node --test test/*.test.js` + vitest + `node --test scripts/*.test.mjs`), `npm run doctor`, `npm run reset` (needs the server running), `npm run talk-track`, `npm run content-pack`.
- `npm run e2e` (Playwright, server on 6670; `E2E_SHOTS` keeps screenshots outside the repo). Docker: `docker compose up --build -d` (publishes `127.0.0.1:6650` only).
- Run by hand (not in CI): `bash ~/Development/AI-DEMO-Standalone/scripts/check-drift.sh .`, `.../check-css.sh .`, `node ~/Development/demo-kit-base/scripts/conformance.mjs . --new` (rule 18 only warns).
- Use globs for node:test, never a directory. Never parse node:test stdout: use exit codes or `--test-reporter=spec`.

## Rules that bite
- **Customer neutrality is a hard rule.** No customer, company, person or identity-provider name, no real host (only `.example` / `.invalid`), no customer scope or business term. Use "Example Corp", `items.read`, `price-lookup`. The neutrality test reads `~/.config/demo-kit/forbidden-strings.txt` (or `FORBIDDEN_STRINGS_FILE`); never print or copy that file. Before reporting: `git log -p --all | grep -cF -f ~/.config/demo-kit/forbidden-strings.txt` must print 0.
- **Flow shape: 20 messages, six phases, the first is the catalog phase.** Messages 1 to 4: publish, review and list (message 2 is an `organisational` step, no protocol), the member adds it for free (UNVERIFIED), it appears as `added, not signed in`. The first 401 (message 6) is called at the `mcp_server_url` of the catalog record. The catalog is an invented teaching model: what a real review checks is UNVERIFIED, and no text may claim a real assistant's catalog works this way or name a real store or company. `unlisted_connector` is the toggle for this phase. Renumbering messages touches `definition.js`, `flow.js`, `server/diagrams/authorization-flow.json`, the web `lib/phases.js` UNVERIFIED_STEP keys, the docs tables and the e2e script.
- **The diagram is diagram-studio/1 data** (`server/diagrams/authorization-flow.json`, validated by `server/src/diagramStudioValidate.js`, loaded by name from `GET /api/diagram`). Nothing in the web code lists boxes or arrows. `server/test/diagram.test.js` pins the data to `definition.js` (ids, ends, titles, words): change both together.
- **Mock | Live toggle in the header of every page**; Mock is the only mode. Live is refused (`POST /api/mode` answers 409 `live_not_supported`) with an honest message and the page stays in Mock. Do not add a live mode without the owner. No `MODE` env var.
- **Settings:** only the shared `~/Development/.env` (or `STANDALONE_ENV`), parsed with `util.parseEnv`, and only the key `MCP_FLOW_WORKSPACE` (`server/src/settings.js`). No per-app `.env` loader, no credential is read or held. Shell variables (`MCP_FLOW_PORT`, `MCP_FLOW_STUB_BASE`, `MCP_FLOW_BIND`) are per run.
- **Netguard** (`server/src/netguard.js`, with a self-test incl. UDP send and connect) goes on before anything listens; the flow suite runs under it and asserts zero attempts.
- Ports only 6650-6699 (server 6650, actors 6651-6655, vite 6660, e2e 6670, tests 6671-6699). The wire's `fetch` refuses 6665-6669, 6679 and 6697, so no actor may use them. Never 8080-8086, 5173, 3900, 4000, 4400, 4510, 4600-4601, 18080/19080/19090.
- Never `crypto.generateKeyPair(Sync)` for EC (aborts on Node 20 in CI): keys come from `createECDH('prime256v1')` + JWK import (`server/src/jwt.js`).
- Tokens are shown raw and labelled MOCK-ISSUED on purpose. Passwords, OTPs, the gateway client secret, Basic credentials and secret-shaped strings are redacted (`server/src/redaction.js`).
- The control API binds 127.0.0.1, has a strict Host guard, an Origin / Sec-Fetch-Site guard, JSON-only bodies, accepts no credential header, and 500s never leak.
- Tests need no wall-clock sleeps: expiry uses the injectable clock (`server/src/clock.js`).
- Web UI: shared stylesheet `web/src/styles/standalone-ui.css` vendored byte-for-byte (never edit it), app CSS in `web/src/app.css` is tokens only (no colour literal, no `prefers-color-scheme`, no `!important`, breakpoints 600/900). Phase colours are tokens plus a class on the edge and an SVG marker (`arrow-<phase>`). Run buttons use `aria-disabled`, not `disabled`, so focus stays. Diagram box positions live in `useDiagramPositions` (Reset restores the data's positions); its `apply` must return the same object when nothing moved or React Flow loops. All displayed run strings go through `Inert`. The simulation banner is on every tab and in presenter mode (P / Esc; modifier keys ignored).
- Reset is queued behind any run in flight (`runtime.reset()` returns a promise; await it). Run ids keep counting across resets.
- `docs/talk-track.md` is generated from `server/src/talkTrack.js` (`npm run talk-track`); `content-pack.json` from `npm run content-pack`. A test fails if either is stale.
- Docker is OrbStack, never Docker Desktop. Commits: `mcp-flow: ...` ending with the Co-Authored-By trailer. Never push or create a GitHub repo without the owner.
- Product claims (CIMD/DCR, NHI store, PingFederate endpoint names) are labelled UNVERIFIED. Standards are cited by RFC number only.
